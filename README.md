Nova AI Chat is a modern AI powered chatbot mobile application developed using Flutter, Gemini AI and Supabase. The application is designed to provide intelligent real time conversations with advanced AI capabilities in a clean and professional ChatGPT style interface. It combines modern mobile development, artificial intelligence integration and cloud backend services to create a scalable AI assistant application.

The chatbot includes several powerful AI features such as real time conversational chat, code explanation mode, study assistant mode, quiz generation, chat summarization and voice interaction. Users can communicate naturally with the AI while receiving smart responses powered by the Gemini API. The app is designed to help students, developers and general users improve productivity and learning experiences.

Nova AI Chat also includes a complete authentication system with email and password login, secure signup, user session handling and logout functionality. Each user can securely access their own conversations, making the application a fully multi user AI chatbot platform.

For backend services, the project uses Supabase and PostgreSQL to manage authentication, chat history storage, realtime database operations and user-specific conversation management. This ensures that all chats are persistent and securely connected to authenticated users.

The user interface is built with a modern and responsive design inspired by ChatGPT. The app supports dark mode, typing animations, markdown rendering, syntax highlighted code blocks, responsive layouts and smooth user interactions to provide a professional user experience.

Additional advanced features include voice input support, copy and share response functionality and chat history search capabilities. The architecture follows MVVM principles with clean folder structure and reusable components to maintain scalability and maintainability.

The project is developed using Flutter and Dart for frontend development, Supabase and PostgreSQL for backend services, Gemini API for artificial intelligence integration and Provider for state management.
